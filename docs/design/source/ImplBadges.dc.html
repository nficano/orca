ORCA · I3 · BADGES, PIPS AND DOTS

The badge hangs off the tile's top-right corner. Not the label, not the rail.

Four count indicators exist and each has exactly one form: the rail count badge (red, numeric), the Settings alert pip (amber, "!"), the tray title count (plain text), and the account-tab count (plain text). There is no Dock icon, so no Dock badge (app.dock.hide(), LSUIElement).

Settings pip · bottom-right

!Settings

bottom: −2px; right: −4px. 16 × 16, border-radius: 50% (true circle, on the allowlist). "!" is 11/800 in oklch(22% .03 85). Same 2px ring as the badge. Bottom placement keeps it visually distinct from the numeric badge and never collides with it.

1 · DOM and anchor

The badge is a child of .tile, never of the rail item or its label, so it moves with the tile on hover/press. .tile has position: relative and no overflow. Check the chain up to the rail: no ancestor between the tile and the rail may clip. The rail's 8px side padding plus the 12px tile inset leaves room for the 6px overhang.

2 · Box

  • position: absolute; top: -4px; right: -6px
  • min-width: 18px; height: 18px; padding: 0 5px; box-sizing: border-box
  • border-radius: 9px: half the height in px. This gives a circle at 1 digit and a true pill at 2+. Never 50%: on a 25×18 box that renders an egg.
  • display: grid; place-items: center. No line-height hacks.
  • box-shadow: 0 0 0 2px var(--surface-2): a ring in the rail color that separates badge from tile edge. It does not change layout size.

3 · Text

11px / 700, #fff, font-variant-numeric: tabular-nums. 1–99 print as is; 100+ prints 99+. 0 removes the element from the DOM (not opacity: 0), so nothing is announced.

4 · What it counts

Inbox badge = pending requests + unanswered questions across all accounts, independent of the selected tab. Running and Done never get a badge. Same number as the tray title. Source of truth: one pendingCount selector in the main process, pushed to renderer and tray together, so they can't disagree.

5 · Motion

Increment: scale 1 → 1.15 → 1, 160ms ease-out, transform-origin: 100% 0 (top-right corner, so it grows away from the tile). Decrement and removal: no animation. Disabled under prefers-reduced-motion. Never pulse or loop.

6 · Accessibility

Badge and pip are aria-hidden="true". The rail button carries the count: aria-label="Inbox, 3 waiting"; Settings with problems: "Settings, 1 problem".

7 · Pip rules

Shown on Settings only, when any account is unhealthy (hook missing, extension missing, Codex disconnected, shortcut failed). Never on other tiles, never numeric. Clears the moment the last problem resolves.

8 · Tray and tab counts are text

Tray: tray.setTitle(n ? ` ${n}` : '') beside a template image; no rendered badge image, no red. Account tab: count is plain 14/500 --text-2 after the label, gap 6, hidden at 0. Neither is a pill.

9 · Dots

width: 8px; height: 8px; border-radius: 50%; flex: none, in a row with align-items: center; gap: 7px. Settings account rows use 10 × 10. Color is the account color, identical in light and dark. Both width and height must be set; a missing height lets a stretch row turn it into an oval.
