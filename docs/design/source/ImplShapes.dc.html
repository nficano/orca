ORCA · I2 · TOKENS, RADII AND THE CIRCLE RULE

Rounded squares by default. Circles only where listed.

Generated UI over-rounds: pill buttons, circular icon buttons, circular close X's, round tiles. Orca uses none of those. Every radius below is a fixed px token. 50% appears only on the six elements in the circle allowlist, each with explicit equal width and height and flex: none. 9999px and 100% never appear.

Enforce it in CI

// stylelint.config.mjs
export default { rules: {
  'declaration-property-value-disallowed-list': {
    'border-radius': ['/9999px/', '/100%/', '/^\\d{3,}px/'],
  },
  'declaration-property-value-allowed-list': {
    'border-radius': ['/^var\\(--r-(3|5|6|7|8|9|10|12|14|16|18|20)\\)/',
                      '/^(9|11)px$/', '0', '/^\\d+px( \\d+px){1,3}$/'],
  },
}}
// 50% is allowed ONLY in src/styles/circles.css (.dot .swatch .knob .pip .spinner)
// — enforced with an overrides block that disables the allowed-list for that file.
