1

Tray anchor

Tray button is a template image, 18×18 glyph, plus a count when > 0, rendered with tray.setTitle(" 3"), never a badge image. Popover opens with its horizontal center on the tray icon's center (tray.getBounds()), clamped 8px inside the active display's work area. Top edge = menu bar bottom + 6px. No arrow/caret.

2

Popover shell

528 × 748, border-radius: 20px, 1px solid oklch(38% .003 70), bg surface-1, shadow 0 18px 60px rgb(0 0 0/.35), overflow: hidden so children clip to the 20px corner. Height is fixed; content scrolls inside region 5. On displays under 820px tall, height = work area − 48.

3

Rail

Width 88, padding 20 8, gap 20, bg surface-2, right border 1px. Items are 72 wide columns: tile 48×48 r14 (rounded square, not a circle) + 11px label, 6px gap. Active tile bg surface-3; hover 34%. Settings pins to the bottom with margin-top: auto. The tile is the badge anchor (I3): position: relative, never overflow: hidden.

4

Account tabs

Height 52, padding 0 20, gap 20, bottom border 1px 32%. Tab = dot 8 + label 14/600 + count 14/500 muted, gap 6, inner padding 0 4. Active underline: 2px, full tab width, bottom: -1px so it sits on top of the border, square ends. Tabs never wrap; at 4+ accounts they scroll horizontally with no visible scrollbar.

5

Card

Region padding 16, gap 12, overflow-y: auto, overlay scrollbar. Card: padding 14, r14, gap 10, bg surface-card, border 1px 32%, position: relative; overflow: hidden (needed for 8). Inner code block r8, padding 8 10. Radius nesting rule: inner radius = outer − padding, floored at 6 (14 − 14 → 6..8).

6

Card header row

Fixed 22px row, align-items: center, gap 8. Order: risk chip (r6, padding 2 8) → title (14/600, flex: 1; min-width: 0, one line, ellipsis) → wait time (12, muted, never shrinks). The risk chip and wait time are never truncated; only the title gives way.

7

Action row

justify-content: flex-end, gap 8. Left: status text (flex: 1). Then Deny (secondary), then Approve. Approve is always rightmost. Split button: two 32px buttons with a 1px gap, radii 9 0 0 9 and 0 9 9 0, chevron segment padding 0 9. Buttons never wrap to a second line in the card; text shortens first (I5).

8

Countdown bar

Absolute, left/right/bottom: 0, height 3, track 30%, fill = tier color, width = elapsed ÷ tier timeout, updated once per second by a single shared timer. No radius of its own: the card's overflow: hidden clips it to the card corner. Hidden for high risk (no timeout).

9

Footer

Height 40, top border 1px, padding 0 16, 12px muted. Left: cleared-today count. Right: shortcut hint, showing the user's actual binding.

E

Electron window

One BrowserWindow per surface. The window is larger than the popover so the CSS shadow is not clipped; transparent margins pass clicks through.

new BrowserWindow({
  width: 528 + 48, height: 748 + 64,   // 24px side/top margin, 40px bottom for shadow
  frame: false, transparent: true, hasShadow: false,
  resizable: false, movable: false, show: false,
  skipTaskbar: true, alwaysOnTop: true, fullscreenable: false,
  vibrancy: undefined,                 // flat surfaces; tokens own the color
  webPreferences: { contextIsolation: true, sandbox: true, preload }
})
win.setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true })
win.on('blur', hidePopover)            // click outside closes; no close button
// renderer: .pop mouseenter → setIgnoreMouseEvents(false)
//           .pop mouseleave → setIgnoreMouseEvents(true, { forward: true })
